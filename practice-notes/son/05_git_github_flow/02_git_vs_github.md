# 🟩 Git과 GitHub의 차이점  

## 🟢 Git과 GitHub 비교  
Git과 GitHub는 이름이 비슷하여 초보자들이 가장 많이 혼동하는 개념이다.  
하지만 이 둘은 완전히 다른 역할을 수행한다.  


<br><br>

## 🟢 한 줄 비유로 이해하는 차이점  
- Git은 내 컴퓨터 안에서 글을 쓰는 **'워드(Word) 프로그램'**이다.  
- GitHub는 그 워드 파일을 친구들과 함께 수정하고 공유하기 위해 올리는 **'구글 드라이브(Google Drive)'**이다.  

<br><br>

## 🟢 Git vs GitHub 상세 비교표  
| 구분 | Git | GitHub |  
| :--- | :--- | :--- |  
| **성격** | 내 컴퓨터에 설치해서 사용하는 **버전 관리 소프트웨어(도구)** | Git 파일들을 올리고 공유할 수 있는 **웹 서비스(저장소)** |  
| **작동 환경** | 인터넷 연결이 없어도 내 컴퓨터(Local)에서 작동함 | 인터넷이 반드시 연결되어 있어야 접속 및 작동함(Remote) |  
| **주요 역할** | 파일 변경 이력 기록, 되돌리기, 브랜치 나누기 | 코드 원격 백업, 다른 개발자와의 공유 및 협업(PR) |  
| **이용 방법** | 컴퓨터 터미널(Terminal)이나 Git GUI 프로그램 실행 | 웹 브라우저를 통해 github.com 사이트에 접속 |  

<br><br>

## 🟢 요약  
내 컴퓨터에서 소스코드를 안전하게 기록하고 관리할 때는 **Git**을 사용하고,  
그 기록을 다른 팀원들과 합치고 함께 협업하여 프로젝트를 완성할 때는 **GitHub**를 사용한다.  
즉, Git이라는 버전 관리 도구를 원활하게 쓸 수 있도록 도와주는 인터넷 웹 서비스가 바로 GitHub이다.
