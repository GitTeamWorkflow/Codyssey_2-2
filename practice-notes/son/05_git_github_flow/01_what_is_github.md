# 🟩 GitHub 소개  

## 🟢 GitHub란 무엇인가?  
GitHub는 Git으로 관리하는 프로젝트들을 인터넷상에 올려두고, 전 세계의 개발자들이 함께 모여 일할 수 있게 해주는 온라인 공간이다.  
쉽게 비유하자면, Git이 내 컴퓨터 안의 '버전 관리 일기장'이라면, GitHub는 그 일기장을 다른 사람들과 같이 보고 채워 넣는 '인터넷 도서관'과 같다.  

<br><br>

## 🟢 GitHub의 핵심 기능  
GitHub는 단순히 코드를 저장하는 것 이상의 다양한 협업 도구를 제공한다.  

<br><br>

### 🟡 1. 백업 기능 (Backup)  
- 내 컴퓨터가 갑자기 고장 나거나 잃어버려도 코드가 날아가지 않도록 인터넷에 안전하게 보관해 준다.  

<br><br>

### 🟡 2. 협업 기능 (Collaboration)  
- 한 프로젝트를 여러 명이 동시에 개발할 때 각자 작업한 코드를 인터넷상에서 쉽게 합칠 수 있다.  
- 누가 어떤 코드를 고쳤는지 추적하기 쉽다.  

<br><br>

### 🟡 3. 오픈 소스 참여 (Open Source)  
- 전 세계 누구나 사용할 수 있도록 공개된 코드(오픈 소스)를 가져와 공부하거나 직접 수정 제안을 보낼 수 있다.  
- 전 세계 개발자들과 소통하며 배울 수 있다.
