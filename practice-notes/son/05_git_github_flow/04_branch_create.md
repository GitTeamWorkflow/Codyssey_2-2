# 🟩 브랜치 생성 및 작업  
## 🟢 브랜치란 무엇인가?  
브랜치(Branch)는 나뭇가지라는 뜻이다.  
기본 뼈대가 되는 중심 코드에서 가지를 뻗어 나와 나만의 안전한 작업 공간을 만드는 기능이다.  
다른 사람의 코드에 영향을 주지 않고 안전하게 새로운 기능을 개발할 수 있다.  

<br><br>

## 🟢 실습하기: 새로운 기능 개발을 위한 브랜치 만들기  

<br><br>

### 🟡 1. 현재 브랜치 상태 확인하기  
터미널을 열고 아래 명령어를 입력하여 내가 지금 어떤 브랜치에 있는지 확인한다.  
```bash
git branch
```

<br><br>

#### ⚫️ 명령어 해설  
| 명령어 | 풀네임 (Full Name) | 기능 해설 |  
| :--- | :--- | :--- |  
| git | Global Information Tracker | 버전 관리 시스템 도구를 실행한다. |  
| branch | branch (나뭇가지) | 현재 만들어져 있는 브랜치 목록을 보여주고, 내가 있는 브랜치 옆에 `*`를 표시해 준다. |  

<br><br>

### 🟡 2. 새로운 브랜치 만들고 이동하기  
새로운 기능을 만들기 위해 브랜치를 새로 생성하고 그리로 이동한다.  
```bash
git checkout -b feature/login
```
또는 최신 Git 버전을 사용한다면 아래 명령어를 권장한다.  
```bash
git switch -c feature/login
```

<br><br>

#### ⚫️ 명령어 해설  
| 명령어 | 풀네임 / 옵션 의미 | 기능 해설 |  
| :--- | :--- | :--- |  
| git checkout | checkout (확인하고 가다) | 다른 브랜치로 작업 공간을 전환하는 명령어이다. |  
| -b | branch (나뭇가지) | 브랜치를 새로 생성함과 동시에 그 브랜치로 바로 이동하라는 옵션이다. |  
| git switch | switch (전환하다) | 브랜치 이동 기능만 안전하게 수행하기 위해 새로 만들어진 명령어이다. |  
| -c | create (만들다) | 브랜치를 새로 생성하고 이동하라는 옵션이다. |  

<br><br>

### 🟡 3. 파일 수정하고 저장(Commit)하기  
파일을 수정하고 변경 사항을 로컬 저장소에 저장한다.  
```bash
git add login.txt
git commit -m "feat: 로그인 화면 파일 추가"
```

<br><br>

#### ⚫️ 명령어 해설  
| 명령어 | 풀네임 / 옵션 의미 | 기능 해설 |  
| :--- | :--- | :--- |  
| git add | add (더하다) | 변경된 파일을 커밋 대기 상태(Staging Area)로 올린다. |  
| git commit | commit (약속하다, 제출하다) | 대기 상태에 있는 파일들을 기록으로 영구 저장한다. |  
| -m | message (메시지) | 커밋 기록에 남길 메모(설명)를 작성하는 옵션이다. |  

<br><br>

### 🟡 4. 원격 저장소에 내 브랜치 올리기  
컴퓨터에 저장된 내 브랜치를 인터넷 상의 GitHub 원격 저장소로 올려야 한다.  
```bash
git push -u origin feature/login
```

<br><br>

#### ⚫️ 명령어 해설  
| 명령어 | 풀네임 / 옵션 의미 | 기능 해설 |  
| :--- | :--- | :--- |  
| git push | push (밀어내다) | 로컬 컴퓨터의 저장 이력을 원격 저장소로 전송한다. |  
| -u | set-upstream (흐름의 위쪽을 설정하다) | 최초에 한 번만 설정해 두면, 다음부터는 `git push`만 입력해도 자동으로 이 브랜치로 연결되게 해준다. |  
| origin | origin (근원, 기원) | 내 컴퓨터와 연결된 기본 원격 저장소(GitHub 주소)의 별칭이다. |  
| feature/login | feature/login | 원격 저장소에 새로 만들고 올릴 브랜치의 이름이다. |
